# Windows 桌宠 v0.12

这是一个基于 Python 3.14 和 PySide6 的轻量 Windows 桌宠。v0.12 对
全部动作进行视觉一致性审计，统一人物尺度、主体锚点和动作首尾过渡。

## v0.12 改进

- 全动作主体定位
  - 39 个动作统一按人物主体定位，不再按整张透明图居中
  - 爱心、问号、叹气泡、怒气标记等附加元素不会把人物推向一侧
  - 站立动作统一脚底基线，主体水平中心的帧间波动限制在约 `1.5` 像素内
- 更自然的动作切换
  - 点击、挥手、害羞、困倦、爱心、行礼和时间小动作均从无表情待机进入
  - 动作结束前回到无表情待机，不再从特殊表情直接硬切
  - 跑步新增起步和停步过渡，转身后才开始移动，停稳后再恢复站姿
  - 睡醒、探头跳出和拖拽落地也补齐最终站稳过渡
- 统一拖拽链人物大小
  - 分别校正抓起、悬空、松手下落和落地素材的原生尺度差
  - 松手后的角色不再突然缩小
  - 最终站稳帧与普通待机主体高度保持在约 `3` 像素差内
- 左右探头完全一致
  - 右侧探头由左侧同源素材严格镜像生成
  - 左右两侧的角色大小、线条、动作幅度和播放节奏完全对应
- 新增 `tools/audit_animation_consistency.py`
  - 自动检查人物尺度、水平锚点、脚底基线和常用动作首尾帧
  - 自动检查左右探头是否严格镜像
  - 素材重建后可先运行该脚本，再执行完整测试

## v0.11 改进

- 睡眠会自动结束
  - 入睡后实际睡眠约 `20～40` 秒
  - 时间到后自动播放揉眼、伸懒腰和站起动画
  - 单击仍可提前唤醒，拖拽也会立即结束睡眠状态
  - 自动醒来后重新开始待机、散步、说话和下一次打盹计时

  - 点击触发的惊讶互动由约 `2.1` 秒延长至约 `3.9` 秒
  - 叹气关键表情停留约 `1.9` 秒
- 修正人物大小与位置
  - 挥手内部帧不再比待机矮一截，视觉高度恢复至同一范围
  - 惊讶帧和叹气帧加入独立水平锚点补偿
  - 表情符号、叹气气泡不会再把人物主体推向右侧

- 放慢叹气和小动作

## v0.9 改进

  - 旧素材的单元格底边混入了相邻行的零散轮廓
  - 构建帧表时会清除贴住格子边缘的小碎片，不再把它们误认为脚底
  - 挥手加入普通待机起始／收尾帧，主体中心和脚底基线保持稳定

  - 每次注视约 `3.2～6.2` 秒，触发距离放宽至 `1400` 像素
  - 点击互动结束后会继续跟随鼠标约 `5.2` 秒
- 平时恢复为无表情待机
  - 早晨／白天／夜晚仍影响偶发动作和台词
  - 静止基础画面统一使用无表情角色，不再长时间保持哈欠、笑脸或闭眼

- 表情动作整体放慢
  - 挥手、害羞、困倦等动作增加逐帧停留时间
  - 新增慢速爱心动作，包含起势、比心、爱心停留和自然收势

## v0.8 改进

- 新增真正的静止待机状态
  - 普通、早晨、白天和夜晚状态不再持续循环动画
  - 静止约 `4.5～5.5` 秒后，才播放一组呼吸、眨眼或轻微小动作
  - 小动作播放完会重新进入静止待机
- 修复连续点击造成的角色位移
  - 当前互动没有播完时，后续点击不会重启动画或随机硬切到另一套素材
  - 连续点击仍会正常累计，达到阈值后进入生气状态
  - 普通点击动作池只保留具有 8 张连续关键帧的点击和挥手动画
  - 新增互动主体中心和脚底基线回归检查
- 提高动画流畅度
  - 动画渲染刷新率提升至 `30 FPS`
  - 在关键帧末段加入平滑补间，减少姿势之间的突然跳变
  - 补间仅用于适合平滑过渡的动作，不干扰睡眠锚点、探头定格和拖拽链
- 对话气泡可由单击关闭
  - 气泡显示期间单击角色，会先关闭气泡
  - 这次单击不会额外播放互动动画
  - 拖动角色仍然保持正常拖拽行为
- 修正鼠标左上／右上方向
  - 已确认原素材表中两张斜上方注视图片的坐标标反
  - 现已交换映射，左上和右上会朝正确方向显示

  - 默认在桌宠周围 190 像素内触发

## 直接运行

1. 安装 64 位 Python 3.14，并勾选 Python Launcher。
2. 双击 `run.bat`。

首次启动会建立 `.venv` 并安装 PySide6，后续直接启动即可。

也可以在 PowerShell 中执行：

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 操作

| 操作 | 效果 |
|---|---|
| 左键单击 | 气泡可见时先关闭气泡；否则播放慢速互动，睡眠中则播放唤醒动画 |
| 按住左键拖动 | 大手拎起角色并随鼠标移动 |
| 松开左键 | 播放下落与落地缓冲动画 |
| 拖到左、右边缘 | 落地后播放对应方向的屏幕边缘探头动画 |
| 单击探头状态 | 播放从屏幕边缘跳出、落地和站稳动画 |
| 拖动探头状态 | 立即恢复身体并进入大手拎起拖拽 |
| 偶发注视 | 待机间隙偶尔看向鼠标；点击互动后也会短暂跟随 |
| 短时间连续点击 6 次 | 进入生气状态 |
| `Ctrl` + 鼠标滚轮 | 调整桌宠大小 |
| 右键 | 互动、立即说话、时间功能、散步、睡眠、大小、窗口层级和退出 |

## 桌面层说明

程序默认使用 Qt 的 `WindowStaysOnBottomHint`，因此不会像旧版一样始终盖住浏览器、游戏或工作窗口。
在 Windows 上，它会表现为靠近桌面的低层级透明窗口。右键取消
“桌面层（不压住其他窗口）”后，会临时改为始终置顶；再次勾选即可恢复。

## 打包 EXE

在 Windows 上双击 `build_exe.bat`。完成后文件位于：

```text
dist\MizushioDesktopPet.exe
```

必须在 Windows 上打包 Windows EXE；不能直接用 Linux 生成可正常运行的 Windows EXE。
项目固定使用支持 Python 3.14 的 PySide6 6.10.1 以上版本，并要求 PyInstaller 6.15 以上。

## 代码入口

- `main.py`：程序入口
- `pet_app.py`：动画状态机、补间渲染、互动防重入、时间状态、说话气泡、生气、睡眠、拖拽、
  散步和边缘探头
- `assets/sprite_manifest.json`：素材与行为配置
- `tools/prepare_action_pack.py`：统一整理并合并全部动作素材
- `tests/test_project.py`：素材、配置和动作完整性测试

运行测试：

```powershell
py -3.14 -m unittest discover -s tests -v
```
