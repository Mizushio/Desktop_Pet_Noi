# Windows 桌宠 v0.17

这是一个基于 Python 3.14 和 PySide6 的轻量 Windows 桌宠。v0.17
新增“鼠标绕两圈把她转晕”的互动，两套服装都有独立眩晕素材；消息提示
动作调用入口仍然保留，实际消息来源将在后续版本接入。

## v0.17 改进

- 新增鼠标绕圈互动
  - 仅在角色正在看向鼠标时记录轨迹
  - 顺时针或逆时针连续累计两圈（`720°`）后触发
  - 角色会沿用原有 8 方向注视帧持续转头
- 降低误触
  - 鼠标离角色太近、采样中断或单次瞬移过大时重置
  - 反方向移动会抵消进度，持续反转会重新开始
  - 触发后有 `10` 秒冷却，不会被同一段轨迹重复触发
- 新增两套服装的 8 帧眩晕素材
  - 失焦、左右轻晃、螺旋眼、星环、疲倦恢复
  - 主体高度、核心中心、脚底基线和头顶安全边距逐帧检查
  - 动作约 `4.7` 秒，首尾都经过无表情待机
- 右键新增“预览晕头转向动作”，无需实际绕圈即可验收素材
- 保留深绿洋装为首次启动默认服装和 v0.16 的挥手修正

## v0.16 改进

  - 脚底保持同线，头顶位置波动限制在 `2 px` 内

  - 不再只检查总高度，同时检查头顶位置、有效帧高度和头顶轮廓
  - 若源素材再次在网格边界截出水平直线，构建和测试会直接失败

## v0.13 改进

  - 信封是独立动作特效，不会改变角色服装或成为永久配件

- 新增四个可调用动作

  - `message_notify_hold`：可循环保持提示

- 新增公开调用入口 `play_message_notification()`
  - 当前只负责播放素材，不读取聊天软件、邮件或其他消息来源

- 消息动作使用独立核心锚点

## 直接运行

1. 安装 64 位 Python 3.14，并勾选 Python Launcher。
2. 双击 `run.bat`。

首次启动会建立 `.venv` 并安装 PySide6，后续直接启动即可。

也可以在 PowerShell 中执行：

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 操作

| 操作 | 效果 |
|---|---|
| 左键单击 | 气泡可见时先关闭气泡；否则播放慢速互动，睡眠中则播放唤醒动画 |
| 按住左键拖动 | 大手拎起角色并随鼠标移动 |
| 松开左键 | 播放下落与落地缓冲动画 |
| 拖到左、右边缘 | 落地后播放对应方向的屏幕边缘探头动画 |
| 单击探头状态 | 播放从屏幕边缘跳出、落地和站稳动画 |
| 拖动探头状态 | 立即恢复身体并进入大手拎起拖拽 |
| 偶发注视 | 待机间隙偶尔看向鼠标；点击互动后也会短暂跟随 |
| 注视期间让鼠标连续绕角色两圈 | 跟随转头后播放晕头转向动作 |
| 短时间连续点击 6 次 | 进入生气状态 |
| 右键 → 预览消息提示动作 | 播放一次预制消息提示动画 |
| 右键 → 预览晕头转向动作 | 直接播放一次眩晕动画 |
| 右键 → 换装 | 在“经典女仆装”和“深绿洋装”之间即时切换 |
| `Ctrl` + 鼠标滚轮 | 调整桌宠大小 |
| 右键 | 互动、换装、立即说话、时间功能、散步、睡眠、大小、窗口层级和退出 |

## 桌面层说明

程序默认使用 Qt 的 `WindowStaysOnBottomHint`，因此不会像旧版一样始终盖住浏览器、游戏或工作窗口。
在 Windows 上，它会表现为靠近桌面的低层级透明窗口。右键取消
“桌面层（不压住其他窗口）”后，会临时改为始终置顶；再次勾选即可恢复。

## 打包 EXE

在 Windows 上双击 `build_exe.bat`。完成后文件位于：

```text
dist\MizushioDesktopPet.exe
```

必须在 Windows 上打包 Windows EXE；不能直接用 Linux 生成可正常运行的 Windows EXE。
项目固定使用支持 Python 3.14 的 PySide6 6.10.1 以上版本，并要求 PyInstaller 6.15 以上。
