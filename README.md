# Windows 桌宠 v0.6

这是一个基于 Python 3.14 和 PySide6 的轻量 Windows 桌宠。v0.6 重点修复打盹动画的
主体位移，并重做屏幕边缘探头的停顿节奏和单击跳出过渡。

## v0.6 改进

- 修复打盹时个别帧让角色突然位移
  - 睡眠泡泡和零散透明边缘像素不再参与角色定位
  - 坐下、犯困、睡眠和唤醒共用稳定的主体横向锚点
  - 实际落地点统一，保留合理的坐下与伸懒腰高度变化
- 靠边探头改为“播放一次后定格”
  - 进入动作和一次完整探头动作播放完后，停在自然探头姿势
  - 定格约 7～18 秒后偶尔眨眼／歪头一次，然后再次定格
  - 不再持续机械循环动画
- 新增 8 帧屏幕边缘跳出动画
  - 单击探头状态后，从屏幕边缘发力、小跳、落地并站稳
  - 左右两侧自动使用正确方向
  - 跳出完成后恢复普通待机，不再直接硬切站姿
- 新增睡眠主体锚点、落地点、探头定格和跳出动作回归测试

## v0.5 已有改进

- 修复打盹时角色每帧忽大忽小
  - 不再把每一帧单独放大到格子上限
  - 同一套动作始终使用同一个固定缩放比例
  - 坐下、蜷缩、落地等动作只改变姿势，不会让头部和身体突然变大
- 大手拎起、悬空、下落与落地也改用统一缩放标准
- 全新 8 帧跑步循环
  - 小步快跑、手臂自然摆动
  - 头发和裙摆带有连续的跟随运动
  - 左右移动共用同一套高质量素材并自动镜像
- 新增素材尺寸回归测试，自动检查待机、互动和跑步帧的异常缩放

## v0.4 已有功能

- 默认位于桌面层，不再始终压在其他程序窗口上
  - 默认使用 `WindowStaysOnBottomHint`
  - 右键菜单可临时取消“桌面层”，切换为置顶显示
- 重做左侧、右侧探头素材
  - 屏幕边缘本身就是遮挡边界
  - 素材内不再绘制墙板、门框或灰色矩形
  - 角色的身体在帧画布边界处自然截断，贴到屏幕边缘后形成探头效果
  - 已删除顶部探头素材和顶部触发
- 新增非站姿动作
  - 逐渐坐下
  - 坐着犯困
  - 坐姿睡眠与呼吸循环
  - 揉眼、伸懒腰、起身
- 长时间没有鼠标互动时自动打盹
  - 默认无操作 60～120 秒后触发
  - 点击睡着的桌宠只播放唤醒动画，不会立刻接普通点击动作
  - 右键可关闭自动打盹，或立即触发一次
- 拖拽加入完整特效
  - 开始拖动：大手从上方拎住角色后背衣服并提起
  - 拖动中：角色悬空晃动，头发与裙摆摆动
  - 松开：大手松开，角色短距离下落
  - 落地：蹲下缓冲、轻微回弹、重新站稳
- 动作系统支持连续动作链
  - 睡眠、唤醒、拖拽与落地不再被中途硬切回站姿
  - 每一帧仍可独立配置停留时间
- 保留自然待机、慢速点击互动、偶发散步、尺寸调整、位置记忆与 EXE 打包

## 直接运行

1. 安装 64 位 Python 3.14，并勾选 Python Launcher。
2. 双击 `run.bat`。

首次启动会建立 `.venv` 并安装 PySide6，后续直接启动即可。

也可以在 PowerShell 中执行：

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 操作

| 操作 | 效果 |
|---|---|
| 左键单击 | 随机播放慢速互动；睡眠中则播放唤醒动画 |
| 按住左键拖动 | 大手拎起角色并随鼠标移动 |
| 松开左键 | 播放下落与落地缓冲动画 |
| 拖到左、右边缘 | 落地后播放对应方向的屏幕边缘探头动画 |
| 单击探头状态 | 播放从屏幕边缘跳出、落地和站稳动画 |
| 拖动探头状态 | 立即恢复身体并进入大手拎起拖拽 |
| `Ctrl` + 鼠标滚轮 | 调整桌宠大小 |
| 右键 | 互动、散步、睡眠、大小、窗口层级和退出 |

## 桌面层说明

程序默认使用 Qt 的 `WindowStaysOnBottomHint`，因此不会像旧版一样始终盖住浏览器、游戏或工作窗口。
在 Windows 上，它会表现为靠近桌面的低层级透明窗口。右键取消
“桌面层（不压住其他窗口）”后，会临时改为始终置顶；再次勾选即可恢复。

## 打包 EXE

在 Windows 上双击 `build_exe.bat`。完成后文件位于：

```text
dist\MizushioDesktopPet.exe
```

必须在 Windows 上打包 Windows EXE；不能直接用 Linux 生成可正常运行的 Windows EXE。
项目固定使用支持 Python 3.14 的 PySide6 6.10.1 以上版本，并要求 PyInstaller 6.15 以上。

`assets/sprite_manifest.json` 可调整：

- 每一个动画帧的独立停留时间
- 点击动作池和随机待机动作池
- 自动行走的等待时间、持续时间、移动速度和默认开关
- 自动睡眠开关与无操作等待时间
- 显示尺寸、可选缩放比例
- 左右边缘触发距离、触发延迟、定格后的偶发动作间隔和跳出移动时间
- 默认窗口层级

新增素材源文件：

- `assets/character_edge_peek_v2_keyed.png`：无墙板的左右探头原图
- `assets/character_sleep_actions_keyed.png`：坐下、睡眠、唤醒原图
- `assets/character_drag_actions_keyed.png`：大手拖拽与落地原图
- `assets/character_run_actions_keyed.png`：全新 8 帧跑步原图
- `assets/character_peek_exit_keyed.png`：8 帧屏幕边缘跳出原图
- 同名但不含 `_keyed` 的 PNG：已清除背景、用于构建最终帧表

旧版的墙板／顶部探头源文件已从 v0.4 项目中移除；如需比较，可在 v0.3
压缩包中查看。

重新构建最终帧表：

```powershell
py -3.14 -m pip install -r requirements-tools.txt
py -3.14 tools\prepare_action_pack.py
```

## 代码入口

- `main.py`：程序入口
- `pet_app.py`：动画状态机、互动、睡眠、拖拽、散步和边缘探头
- `assets/sprite_manifest.json`：素材与行为配置
- `tools/prepare_action_pack.py`：统一整理并合并全部动作素材
- `tests/test_project.py`：素材、配置和动作完整性测试

运行测试：

```powershell
py -3.14 -m unittest discover -s tests -v
```
